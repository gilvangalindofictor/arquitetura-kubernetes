### 4. ESO Still Failing After Vault Seed

**Observation**: ExternalSecrets still reported "Secret does not exist"

**Root Cause #2**: ClusterSecretStore misconfiguration

```bash
$ kubectl get clustersecretstore vault-backend -o yaml | grep serviceAccountRef -A3
serviceAccountRef:
  name: external-secrets
  namespace: external-secrets-system  # ❌ WRONG!
```

**Reality**: ESO pods running in `staging-security-externalsecrets`

```bash
$ kubectl get pods -A | grep external-secrets
external-secrets-system            external-secrets-6c469ff76f-k7kcm     0/1     CrashLoopBackOff   68
staging-security-externalsecrets   external-secrets-86db54d8f4-bmwsh     1/1     Running            0
```

**Fix #1**: Patch ClusterSecretStore

```bash
kubectl patch clustersecretstore vault-backend --type='json' \
  -p='[{"op":"replace","path":"/spec/provider/vault/auth/kubernetes/serviceAccountRef/namespace","value":"staging-security-externalsecrets"}]'
```

### 5. ESO Still Failing After ClusterSecretStore Patch

**Root Cause #3**: Vault Kubernetes auth role namespace binding

```bash
$ curl -H "X-Vault-Token: $VAULT_TOKEN" http://localhost:8200/v1/auth/kubernetes/role/eso-reader | jq -r '.data.bound_service_account_namespaces'
["external-secrets-system"]  # ❌ WRONG!
```

**Fix #2**: Update Vault Kubernetes auth role

```bash
curl -X POST \
  -H "X-Vault-Token: $VAULT_TOKEN" \
  -d '{"bound_service_account_names":["external-secrets"],"bound_service_account_namespaces":["external-secrets-system","staging-security-externalsecrets"],"policies":["eso-reader"],"ttl":"900","max_ttl":"3600"}' \
  http://localhost:8200/v1/auth/kubernetes/role/eso-reader
```

## Lessons Learned

1. **Namespace migrations require coordinated updates** across:
   - Kubernetes resources (ExternalSecrets, ClusterSecretStore)
   - Vault auth backend roles (`bound_service_account_namespaces`)
   - Application configs referencing namespaces

2. **ExternalSecrets debugging checklist**:
   - [ ] Vault KV path exists (curl verify)
   - [ ] Vault policy allows ESO ServiceAccount to read path
   - [ ] Vault Kubernetes auth role bound to correct namespace
   - [ ] ClusterSecretStore references correct ServiceAccount namespace
   - [ ] ESO controller pods Running in expected namespace

3. **Terraform modules with incomplete dependencies block entire apply**
   - Workaround: Use Vault API directly for time-critical fixes
   - Long-term: Ensure modules are independently testable
