# Skill: Frontend Patterns

**Nota**: Este projeto é IaC/plataforma. Frontend patterns se aplicam a futuras aplicações web que rodarão na plataforma.

## Component Patterns

- Atomic Design (atoms, molecules, organisms)
- Container/Presentational separation
- Hooks para lógica reutilizável

## State Management

- Local state: `useState`, `useReducer`
- Global state: Context API, Zustand, Redux (quando necessário)
- Server state: React Query, SWR

## Styling

- CSS Modules, Styled Components, Tailwind
- Responsivo mobile-first
- Design system tokens

## Regras

1. **data-testid** em todos os componentes (para RPA)
2. **Validação client + server** (never trust client)
3. **No secrets** no código frontend
